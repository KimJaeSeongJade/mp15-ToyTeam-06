## 1. 프로젝트 명 및 컨셉 확정

## 2. 프로젝트 에셋 일부 선정

- 플레이어/맵 : 시트에 등록한 조사해온 후보 기반으로 `플레이어`, `튜토리얼 맵`, `던전 입장 후 맵` 고정
- 몬스터 에셋 : 미노타우루스 아바타 에셋이 로우폴리 대비 **필수 애니메이션**(공격, 이동, 피격, 사망 등)이 잘 갖춰져 있어 긍정적 평가

## 3. GitHub Projects 관리 방식 (테이블 형식 채택)

- 관리 방식 : GitHub Projects의 **테이블(Table) 형식** 채택
- 채택 이유 : 칸반 보드는 서브 이슈가 많아지면 시각적으로 복잡하지만, 테이블 형식은 워크시트처럼 계층 구조를 펼쳐보기 유용함
- 운영 규칙 : PM이 큰 틀과 세부 서브 이슈를 할당 및 관리
- 작성자(담당자)가 직접 본인을 이슈의 담당자로 지정하고 작업 일정 설정

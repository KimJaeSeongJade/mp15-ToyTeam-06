  -  UI
     -

     - Boss방 진입 여부 선택 창
     - 플레이어 타임 UI
     - Score UI

### IDamagable
### Interactable
- 파괴가능한 ItemBox

- Trap
  - 바닥에서 튀어나오는 가시 트랩
### Player
- **기본 세팅**
  - Idle
  - 대시
  - 구르기(무적상태)
  - 스테미너 개수
  - 체력 개수
  - 이동 속도
- **이동 및 행동**
  - 입력값 수집
  - 방향 벡터 계산
  - 이동 방향으로 회전
  - 이동 애니메이션 적용
  - 일화용 아이템 사용
- **상호작용**
  - 아이템 충돌
  - 패링기능 구현
- **타겟팅**
  - 특정키 입력 시 타겟팅 활성화
  - 벽에 가려져있는지 판별
  - 화면 중앙에 위치한 적 선택
  - 타겟 유지 / 변경 로직
- **공격(구조체로 구현)** 
  - 쿨타임
  - 투사체 제작
  - 투사체 적중
  - 공격 애니메이션 적용
  - 콤보공격
    - 1-3단계로 진행되는 공격 에니메이션
- **피격 및 사망**
  - 피격판정
  - HP 0 판정
  - 입력 차단
### Monster
- **기본 세팅**
  - 이름 
  - 프리팹 생성
  - Idle
  - 체력 개수
  - 이동 속도
- **패트롤**
  - 웨이포인트 관리
  - 순환 이동 구현
- **플레이어 감지**
  - 감지 범위
  - 시야각(FOV) 판별
  - FOV 시각화
  - 벽 가려짐 판별
- **추적**
  - 플레이어 위치 추적
  - NavMesh 적용

- **공격**
  - 공격 가능 거리 체크
  - 공격 쿨타임 구현
  - 데미지 전달
- **피격 및 사망** 
  - 피격판정
  - HP 0 판정
  - 아이템 드랍(코인, 아이템)
  - 오브젝트 제거
### Boss
- **기본 세팅**
  - 이름 
  - 프리팹 생성
  - Idle
  - 그로기 게이지
  - 체력 개수
  - 이동 속도
- **보스 몬스터 AI(B-Tree)**
  - 공격
    - 공격 패턴 1
    - 공격 패턴 2
    - 공격 패턴 3
    - 일정 체력 이하일 때부터 추가되는 공격 패턴 (페이즈 변화)
    - 공격 패턴 4
    - 공격 패턴 5
    - 공격 패턴 6
  - 피격 및 사망
    - 경직 게이지 없어질 시 경직 / 넘어지는 판정
    - 피격판정
    - HP 0 판정
    - 아이템 드랍
  
### Item
- 일회성 아이템
  - 회복아이템
  - 투척아이텝
- 플레이어 무기
  - 근접무기
  - 원거리무기

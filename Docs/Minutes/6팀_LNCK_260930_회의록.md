## 5. 상태패턴 (State Pattern) & 구조 핵심 요약

### 주요 설계 구조

1. Input Script (입력관리) : `Input` 스크립트 단에서 입력 유무를 `bool` 타입 등으로
	관리하여 각 상태 및 컨트롤러의 중복검사 코드 방지.
2. Context: 플레이어, 몬스터, 보스 별 독립 Context 보유. 컨트롤러가 `Awake` 시점에 주입하며, 입력값 및 데이터 접근 창구로 활용.
3. State Machine(상태머신): 상태 간의 전환 전담 제어.

### State 생명주기
- Enter: 상태진입 시 실행 (걷기 시작, 애니메이션 실행 등)
- Tick: 매 프레임 `Update` 단계에서 `Context`를 참조해 로직 진행
- Exit: 상태 탈출 시 실행 (걷기 종료, 변수 초기화 등)
